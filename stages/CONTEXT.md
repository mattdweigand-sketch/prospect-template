# Main prospecting stages

The numbered folders show the usual progression from finding an account to following up after a send. Each stage owns a short contract and one procedure. Start at the stage matching the user's request; an already named account can start at research, and a proven send can go directly to follow-up.

| Stage | Job |
|---|---|
| `01-prospect/CONTEXT.md` | Find and qualify accounts; propose eligible CRM claims |
| `02-research/CONTEXT.md` | Prove a named account's public signals |
| `03-outreach/CONTEXT.md` | Propose one evidence-backed email draft |
| `04-followup/CONTEXT.md` | Propose a Task from a proven send |

Read the selected contract, then its procedure and scoped references. `../AGENTS.md` owns skill routing; numbers do not authorize automatically running the next stage.

Handoffs and exact review remain in the chat and native provider records under `../CONTEXT.md`. No empty output folders or customer records are stored here.
